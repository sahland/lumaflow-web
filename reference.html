Practice: a sidebar, fixed heading and scrollable list.

Start with the working Bootstrap and AppRoot. Add this file and using LumaFlowDocs.NextSteps; to AppRoot. Replace CounterPage with new ResponsiveDashboard() inside its existing Scaffold. Do not add another Mount.

ResponsiveDashboard.cs · complete file
using LumaFlow;

namespace LumaFlowDocs.NextSteps {
    public sealed class ResponsiveDashboard : StatelessWidget {
        public override Widget Build(BuildContext context) => SizedBox.Expand(
            new LayoutBuilder((_, constraints) => {
                var narrow = constraints.MaxWidth < 720f;
                Widget content = narrow
                    ? new Column(new Widget[] {
                        new Text("Navigation: Projects"),
                        new Expanded(BuildProjects())
                    }, gap: 16f)
                    : new Row(new Widget[] {
                        new SizedBox(new Text("Navigation: Projects"), width: 180f),
                        new Expanded(BuildProjects())
                    }, gap: 24f);
                return SizedBox.Expand(new Padding(content, EdgeInsets.All(24f)));
            }));

        private static Widget BuildProjects() {
            var rows = new Widget[40];
            for (var i = 0; i < rows.Length; i++)
                rows[i] = new SizedBox(new Text($"Project {i + 1}"), height: 36f);
            return SizedBox.Expand(new Column(new Widget[] {
                new Text("Projects — this heading stays visible"),
                new Expanded(new ScrollView(new Column(rows, gap: 8f)))
            }, gap: 16f));
        }
    }
}

How space is allocated

  1. Scaffold supplies a finite screen height. SizedBox.Expand carries the fill requirement through composed wrappers.
  2. LayoutBuilder reads its branch's width, not Screen.width. Below 720 UI units navigation moves above content; otherwise it occupies 180 units on the left.
  3. Expanded takes remaining width in the wide Row, or remaining height below navigation in the narrow Column.
  4. The inner Column leaves its heading outside ScrollView. Expanded gives scrolling finite height; only rows scroll.

Check: compare Game at 1100×720 and 540×720. Scroll to Project 40. The heading stays visible and the page does not grow to contain all rows.

UI units are not always physical pixels.

Panel Settings Scale = 1 makes comparison simple. LayoutBuilder reports available UI space at other scales too. Choose a content breakpoint, not a phone model.

Three common failures

  • Expanded inside scroll content: no finite remaining height exists along the scrolling axis. Bound the viewport, not content.
  • A wrapper separates Expanded from Row/Column: use Expanded(Padding(child, ...)), not Padding(Expanded(child), ...).
  • ScrollView has no finite height: trace the chain from Scaffold to the viewport; check SizedBox.Expand and Expanded placement.

ScrollView creates all 40 teaching rows at once. For thousands of records, use virtualized ListView<T>.

Mounting, widgets and inherited context.

The application owns the external UIDocument root; LumaFlow owns a single host below it. The returned handle is the lifecycle boundary.

TypeUse it for
LumaFlow.MountCreate one mounted widget tree.
MountHandleDispose, rebuild, restart and capture diagnostics.
Widget / WidgetKeyImmutable descriptions and stable sibling identity.
State<T> / ReactiveBuilder<T>Explicit state and a local reactive boundary.
Theme / MediaQuery / LocalizationsInherited application configuration.

Typed building blocks over the native flex model.

Row, Column, Expanded, Flexible and Spacer express flex composition. Use LayoutBuilder at a responsive boundary; use ScrollView and ListView<T> for scrolling content.

Constraint rule

Flex children need bounded room on their main axis. A scroll view intentionally leaves one axis unbounded, so combine the two only with a clear constraint boundary.

Controls, form state and product-level themes.

Use Button, IconButton, Pressable, TextField, Checkbox, Radio<T>, Switch, Slider and Dropdown<T> for interaction. Form, FormState and FormField<T> make validation explicit.

ThemeData supplies component defaults. An explicit style overrides only the fields it provides; it does not discard the rest of the active theme.

Retained navigation and a separate overlay stack.

Navigator, Route and NavigationSnapshot own route history. OverlayController, Dialog, Toast, TooltipAnchor and drawers own transient content above it. Keep each controller outside a build method.

Animations, semantics and locale resources.

TweenAnimationBuilder<T> and AnimatedOpacity provide local implicit animation. Semantics, SemanticsProperties and ExcludeSemantics add or remove application meaning. Locale, Localizations, TextScaler and TextScale scope language and scalable typography.

Inspect without taking ownership.

MountHandle.CaptureDiagnostics() returns an immutable WidgetTreeDiagnostics snapshot. In the Editor, open Window › LumaFlow › Widget Inspector to inspect active mounts and copy a tree for an issue report.
