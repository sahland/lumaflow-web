01 / Install

Add the package, then import the sample.

LumaFlow is published as com.lumaflow.ui. Add it through Unity Package Manager from your chosen package source, then import the Getting Started sample from Package Manager.

Current distribution

The public package URL is being prepared. This page avoids inventing an installation command that is not yet available.

02 / Mount

Keep ownership of your UIDocument.

LumaFlow mounts into a root VisualElement that your application already owns. Pair the mount lifecycle with your MonoBehaviour lifecycle and dispose it when the host is disabled.

AppBootstrap.cs
private MountHandle? _mount;

void OnEnable() {
  _mount = LumaFlow.LumaFlow.Mount(
    new Text("Hello, LumaFlow"),
    document.rootVisualElement);
}

void OnDisable() {
  _mount?.Dispose();
}

03 / Compose

Describe the screen, not its update sequence.

Widgets are immutable C# descriptions. Compose layouts and controls with familiar typed building blocks; LumaFlow reconciles compatible widget updates against retained UI Toolkit elements.

01

Typed layout

Rows, columns, constraints and scrolling follow UI Toolkit’s flexbox model.

02

Retained by default

Compatible elements keep their identity instead of being recreated for each update.

04 / State

Let the state-owning branch update itself.

State<T> is an explicit reactive value. A mounted branch that reads it is the branch that updates, keeping change propagation local and visible in source.

Counter.cs
var count = new State<int>(0);

Widget Counter() => new Column(
  gap: 8f,
  children: new Widget[] {
    new ReactiveBuilder<int>(
      count, value => new Text($"Count: {value}")),
    new Button("Increment", () => count.Value++)
  });
Design principle

Keep state close to the UI that owns it. Lift it only when a sibling, route or application boundary genuinely needs to share it.

05 / Layout

Make width a fact of the build, not a global guess.

LayoutBuilder receives the resolved constraints of its location in the tree. Use it to choose a compact or wide composition, and keep Expanded and Flexible directly under a Row or Column.

ResponsiveCards.cs
Widget ResponsiveCards(Widget first, Widget second) =>
  new LayoutBuilder((context, constraints) =>
    constraints.MaxWidth < 640f
      ? new Column(new[] { first, second }, gap: 12f)
      : new Row(new Widget[] {
          new Expanded(first),
          new Expanded(second),
        }, gap: 12f));
A practical layout rule

Read the Layout Contract before combining scrolling, fixed heights and flex children. A scroll view supplies an unbounded axis; a flex child needs bounded room to divide.

06 / Navigation

Retain controllers outside Build.

Navigator and OverlayController own retained stacks. Create them at an application boundary, mount each beneath its matching host, and use keyed Route objects when identity or restoration matters.

ProjectFlow.cs
var navigator = new Navigator(new Route(
  new WidgetKey("dashboard"),
  new DashboardPage()));

navigator.Push(new Route(
  new WidgetKey($"project:{project.Id}"),
  new ProjectDetails(project),
  RouteTransition.Fade(TimeSpan.FromMilliseconds(180))));

07 / Controls

Keep values outside the control that edits them.

Text fields, toggles, sliders, dropdowns and tabs receive application-owned State<T> or FormField<T>. User input commits the value before onChanged; a programmatic update refreshes the control without replaying the callback.

ProjectTabs.cs
var section = new State<string>("overview");

new Column(new Widget[] {
  new TabBar<string>(section, tabs),
  new Expanded(new TabView<string>(
    section, value => value == "overview"
      ? new OverviewPanel()
      : new ActivityPanel()))
});
Do not replace control behavior to style it.

Wrap LumaFlow controls in product-level widgets and themes. The wrapped control keeps native focus, keyboard interaction and accessibility semantics.

08 / Animation

Animate a local value, then let it settle.

Implicit animations own their scheduler and retarget compatible updates from the value currently displayed. They establish the initial value immediately and cancel their work when the widget unmounts.

FadePanel.cs
var visibility = new State<float>(1f);

new AnimatedOpacity(
  panel,
  visibility,
  TimeSpan.FromMilliseconds(180),
  curve: Curves.EaseInOut,
  onEnd: OnVisibilitySettled);
Respect reduced motion.

Supply disableAnimations: true through MediaQueryData when the application or platform adapter requires it. Normal animations then snap to their target; preserved ones continue deliberately.

09 / Accessibility and localization

Make meaning and language part of the tree.

LumaFlow keeps semantics, keyboard focus and locale resources as separate tree-scoped contracts. Built-in controls expose their roles and state; use Semantics when application-specific content needs an explicit label, hint or action.

ProjectCard.cs
new Semantics(
  new ProjectCard(project),
  new SemanticsProperties(
    label: project.Name,
    hint: "Opens project details",
    role: SemanticsRole.Button,
    enabled: project.CanOpen,
    onTap: () => Open(project)),
  excludeDescendantSemantics: true);
01

Own the resource object

Place strongly typed application strings in Localizations; the framework does not force a loading package or table format.

02

Test on real target devices

The hierarchy is deterministic, but screen-reader speech and touch exploration still need representative platform review.

10 / Inspection

Inspect the retained tree when behavior needs an explanation.

Open Window › LumaFlow › Widget Inspector in Unity. The inspector captures active mounts with widget and state types, native UI Toolkit identity, resolved layout and lifecycle findings.

Diagnostics.cs
using var mount = LumaFlow.Mount(application, root);

WidgetTreeDiagnostics snapshot = mount.CaptureDiagnostics();
Debug.Log(snapshot.ToStringDeep());
Snapshots are non-owning.

They contain values and child snapshots, not live WidgetNode, VisualElement or MountHandle instances. Capture them on Unity’s main thread.
