03 / Ментальная модель

Четыре понятия объясняют почти весь LumaFlow.

Widget

Описание, а не нативное представление

Widget — неизменяемое значение C#. Его перестроение не означает пересоздание UI Toolkit элемента.

Element

Смонтированный экземпляр в retained-дереве

Он управляет жизненным циклом. Совместимое обновление сохраняет прежний VisualElement.

State

Значение с явными зависимостями

При изменении State перестраиваются только прочитавшие его смонтированные ветви.

Key

Идентичность при перемещении

Ключ сохраняет логическую идентичность после перестановки, вставки или удаления детей.
