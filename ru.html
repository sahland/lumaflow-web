Декларативно поверх Unity UI Toolkit

Продуманный UI-слой для Unity.

LumaFlow добавляет декларативную композицию, реактивное состояние, навигацию и виртуализированные списки, оставляя UI Toolkit нативным слоем рендеринга и layout.

01 / Обзор

Опишите интерфейс таким, каким он должен быть сейчас.

Widgets неизменяемы, состояние остаётся явным, а совместимые обновления согласуются с retained UI Toolkit elements вместо замены слоя рендеринга приложения.

02 / Возможности

Базовые части интерфейса приложения — в одной понятной модели.

01

Композиция с намерением

Rows, columns, constraints, scrolling и responsive layouts выражаются типизированными widgets. Themes, text scale и localization наследуются через scopes, а не через неявные globals.

  • Типизированные flex и constraint layouts
  • Component themes и interaction states
  • Accessibility semantics и focus traversal

02

Навигация без связи со сценами

Retained Navigator владеет routes и in-memory snapshots. Overlays управляют dialogs, drawers, popovers, tooltips и toasts отдельным scoped stack.

03

Нативная виртуализация списков

ListView<T> использует UI Toolkit ListView. Монтируются только видимые и recycle-range rows, а не вся исходная коллекция.

04

Явный lifecycle и диагностика

MountHandle освобождается на границе native host. Widget Inspector захватывает immutable snapshots дерева, layout и lifecycle findings без постоянного polling.

03 / Нативно по конструкции

Framework layer, а не второй UI engine.

LumaFlow сопоставляет декларативные widgets с retained UI Toolkit elements. Он не добавляет собственный renderer, JavaScript runtime или ещё одну layout-систему.
