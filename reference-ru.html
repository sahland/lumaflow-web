Практика: боковая область, заголовок и прокручиваемый список.

Начните с рабочего AppRoot и Bootstrap. Добавьте файл ниже и using LumaFlowDocs.NextSteps; в AppRoot. Внутри существующего Scaffold замените CounterPage на new ResponsiveDashboard(). Новый Mount не нужен.

ResponsiveDashboard.cs · полный файл
using LumaFlow;

namespace LumaFlowDocs.NextSteps {
    public sealed class ResponsiveDashboard : StatelessWidget {
        public override Widget Build(BuildContext context) => SizedBox.Expand(
            new LayoutBuilder((_, constraints) => {
                var narrow = constraints.MaxWidth < 720f;
                Widget content = narrow
                    ? new Column(new Widget[] {
                        new Text("Navigation: Projects"),
                        new Expanded(BuildProjects())
                    }, gap: 16f)
                    : new Row(new Widget[] {
                        new SizedBox(new Text("Navigation: Projects"), width: 180f),
                        new Expanded(BuildProjects())
                    }, gap: 24f);
                return SizedBox.Expand(new Padding(content, EdgeInsets.All(24f)));
            }));

        private static Widget BuildProjects() {
            var rows = new Widget[40];
            for (var i = 0; i < rows.Length; i++)
                rows[i] = new SizedBox(new Text($"Project {i + 1}"), height: 36f);
            return SizedBox.Expand(new Column(new Widget[] {
                new Text("Projects — this heading stays visible"),
                new Expanded(new ScrollView(new Column(rows, gap: 8f)))
            }, gap: 16f));
        }
    }
}

Как распределяется место

  1. Scaffold даёт конечную высоту. SizedBox.Expand передаёт требование заполнить область через составные обёртки.
  2. LayoutBuilder читает ширину своей ветки, не Screen.width устройства. Ниже 720 UI-единиц навигация становится строкой сверху; иначе это область шириной 180 слева.
  3. Expanded забирает остаток места в Row/Column: ширину в широкой композиции и высоту под навигацией — в узкой.
  4. Внутренний Column оставляет заголовок вне ScrollView; Expanded отдаёт прокрутке конечную высоту. Скроллятся только строки.

Проверка: сравните Game 1100×720 и 540×720. Прокрутите до Project 40: заголовок остаётся видимым, страница не растягивается до высоты всех строк.

UI-единицы не всегда равны физическим пикселям.

При Scale = 1 сравнение проще. Если масштаб Panel Settings другой, LayoutBuilder всё равно отражает доступное пространство UI. Порог выбирайте по содержимому, не по модели телефона.

Три причины сломанной вёрстки

  • Expanded внутри прокручиваемого контента: по оси скролла нет конечного остатка высоты. Ограничьте viewport, не растягивайте содержимое до бесконечности.
  • Обёртка отделяет Expanded от Row/Column: используйте Expanded(Padding(child, ...)), не Padding(Expanded(child), ...).
  • ScrollView не получил конечную высоту: проследите цепочку от Scaffold до viewport, проверьте SizedBox.Expand и положение Expanded.

ScrollView создаёт все 40 строк сразу — это учебный короткий список. Для тысяч записей используйте виртуализированный ListView<T>.

Полный пример — выше; далее справочные фрагменты. Короткие блоки ниже показывают отдельные API и не являются готовыми файлами. Имена вроде DashboardPage, ProjectDetails или Location обозначают ваши экраны и модели, а не встроенные типы LumaFlow.

Родитель передаёт ограничения. Ребёнок выбирает допустимый размер.

LumaFlow использует flex layout UI Toolkit. Родитель определяет доступную ширину и высоту; ребёнок не может заставить ограниченного родителя стать больше.

Bounded

Размер имеет конечный предел

Expanded может разделить оставшееся пространство между flex-детьми.

Unbounded

Размер не ограничен по оси

ScrollView разрешает содержимому расти по оси прокрутки; делить «оставшееся» пространство там невозможно.

Скроллится тот узел, которому дали ограниченный viewport.

Чтобы прокручивался только список, внешний Column должен иметь ограниченную высоту, а Expanded(ListView) — занять остаток под заголовком. Не оборачивайте весь экран в вертикальный ScrollView.

LocationsPanel.cs
new Column(new Widget[] {
  BuildHeader(),
  new Expanded(
    new ListView<Location>(
      locations, BuildLocation))
});
Expanded нельзя помещать в unbounded ось.

Вертикальный ScrollView сообщает содержимому, что оно может иметь любую высоту. Expanded при этом не знает, какое «оставшееся» пространство делить.

Нативное поведение с внешним состоянием.

Button, IconButton, TextField, Checkbox, Radio<T>, Switch, Slider и Dropdown<T> сохраняют UI Toolkit input/focus behavior. FormState и FormField<T> делают валидацию явной.

История маршрутов и временный UI хранятся отдельно.

Navigator, Route и NavigationSnapshot управляют экранами. OverlayController, Dialog, Toast, TooltipAnchor и drawer управляют временными слоями.

Конфигурация передаётся через context.

Theme, MediaQuery и Localizations задают tree-scoped данные. Semantics добавляет смысл, TextScaler управляет читаемым масштабом, а implicit animation widgets учитывают reduced motion.
